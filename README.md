# 🕸️ Medium Article Web Scraper using Python & BeautifulSoup
This Python project allows you to scrape articles from Medium.com, extract the content, and save it as a .txt file for offline use. The scraper uses BeautifulSoup for web scraping and can clean and structure the text effectively.


Simple Web Scraping Visual Representation

📦 Features:

🌐 Scrapes articles from Medium.com

🧼 Cleans the HTML tags for better readability

🗂️ Saves the content as a .txt file in a dedicated folder

🔗 Input flexibility – Provide any Medium article link

🛠️ Technologies Used:

Python 3.x

BeautifulSoup4

Requests Library

📖 How It Works:

The user inputs a Medium article URL.

The script checks if it's a valid Medium article link.

It fetches the HTML content using the requests library.

BeautifulSoup extracts all the text paragraphs.

The text is cleaned and saved in a folder named scraped_articles.

💡 Why This Project is Useful:

✅ Perfect for data extraction and content analysis.

✅ Can be expanded for NLP projects.

✅ Teaches web scraping fundamentals using Python.
